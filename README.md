# FORMA MARKETPLACE

Мебельный маркетплейс Казахстана.
Версия 1.0.0.

## Возможности
- Регистрация продавцов и покупателей.
- Личные кабинеты.
- Каталог мебели с фотографиями.
- Калькулятор стоимости мебели.
- Корзина и оформление заказов.
- Управление заказами.
- Настраиваемая комиссия от 0 до 15%.
- Административная панель.
- Тестовая оплата и доставка.

## Установка

1. Установить Node.js 24 LTS.
2. Выполнить npm ci --omit=dev.
3. Скопировать .env.example в .env.
4. Установить уникальный SESSION_SECRET.
5. Создать папку uploads.
6. Выполнить npm start.

При ошибке сборки better-sqlite3 могут
потребоваться Python и инструменты сборки C++.

## Создание администратора

Установить переменные окружения:
FORMA_ADMIN_EMAIL
FORMA_ADMIN_PASSWORD

Пароль должен содержать минимум 12 символов.

Выполнить node create-admin.js.

## Адреса

Главная: /
Каталог: /catalog.html
Кабинет продавца: /dashboard.html
Кабинет покупателя: /buyer-account.html
Вход владельца: /admin-login.html

## Коммерческий запуск

Необходимо подключить реальную платёжную
систему и Яндекс Доставку.

Тестовые платежи не считаются выручкой.

Для размещения необходим хостинг
с постоянным хранением базы SQLite
и загруженных фотографий, а также HTTPS.

Необходимо регулярно создавать резервные копии.
